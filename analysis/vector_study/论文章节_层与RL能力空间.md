## X.1 设定与一个反常现象：Steering 有层选择性，而全参 / LoRA 没有

Finding 1 已经表明：RLVR 相对基座模型的增益，**可以被一组加性 steering 向量大部分复现**
（冻结模型，只在若干层的 residual stream 上注入可学习方向，用 on-policy 蒸馏目标 OPD/RFT 训练），
而 SFT / off-policy 蒸馏做不到。这说明该增益具有**低维、可加性**的结构。
我们进而追问：**这种结构落在网络的哪个位置？** 方法是把三类微调分别限制在**低、中、高**层上训练，
看谁还能复现增益。

**表 1（正文主表，需填入 full/LoRA 实测分数）**

| 方法 | 改变的对象 | 低层 | 中层 | 高层 |
|---|---|:--:|:--:|:--:|
| 全参微调 | 该层全部权重 | ✓ | ✓ | ✓ |
| LoRA | 该层权重的低秩增量 | ✓ | ✓ | ✓ |
| **Steering 向量** | residual 上的加性方向 | ✓ | ✓ | **✗** |

反常之处很鲜明：修改一层**实际计算**（权重）的方法（全参、LoRA）**处处有效**；
而加性的 **steering 向量只在网络的中低层有效、在高层失效**。
这个失效不是边缘现象，而是一种训练病态（图 1）：
中低层 steering 使下游准确率稳定提升（AIME reward **+0.33**），向量 norm 平稳收敛；
高层 steering 则出现两种病态——要么 **norm 失控爆炸**（L24–25 → 16.9，约为其他层的 6 倍），
要么 **梯度消失、几乎不动**（L32–33，Δ 仅 +0.03，norm 停在 0.5）。

关键在于：高层**并非没有 RL 信号**——全参和 LoRA 在高层照样能复现增益。
所以 steering 的失效是**"加性方向"这一形式特有的**，而它的层选择性恰恰让我们能把 steering 当作一支**探针**：
*steering 有效的层，就是 RL 增益以"加性方向"形式存在的层。*
本节就把这支探针，转化成对"RL 学到了什么、学在哪里"的回答。

## X.2 论点：在中低层，Steering 向量编码的是一种**推理计算模式**

我们先立正面论点，再（X.3）用它解释高层为何失效。

**论点。** 在中低层，训练得到的 steering 方向**并不指向输出词表**；它落在一个**与输出 token 方向正交**
的子空间里，转而**调制一种内部推理模式**，这种模式由其下游的各层计算出来才真正兑现。

三条证据支撑（完整分析见附录 C.1；两个模型——Qwen3-4B 数学 OPD 与
DeepSeek-R1-Distill-Qwen-7B 指令遵循 OPD——给出一致图景，见附录 C.5）：

1. **方向与词表无关。** 用 logit lens 把每层向量投影到词表（`RMSNorm(v)·W_Uᵀ`），
   所有中低层得到的分布，其熵与**随机向量无异**（图 2）。向量几乎不携带直接的 next-token 信号。

2. **它在结构位置、而非词汇位置上发火。** 与该方向最对齐的 token 是**句法 / 角色 / 控制位置**——
   `<think>`、`assistant` 轮次槽位、数学定界符（数学任务）；条件与格式标记（IF 任务）——
   而不是内容词（附录 C.1）。

3. **它的作用经由计算兑现，而非直接注入。** 因果 push-through（注入向量后**跑完剩余各层**）显示：
   尽管 logit lens 是乱码，最终输出却被推向"过渡到作答"的语气（Okay/Alright）。
   即向量设定的是一个**下游才兑现的计算意图**，而不是要直接输出的某个 token。

综合起来：中低层的 steering 向量是一个**任务特定的推理模式方向**。它之所以有效，是因为其下方十几层
把一个加性的"模式"线索翻译成了各位置合适的行为。这就是"**RL 改变的是推理模式**"的确切含义。

## X.3 边界：同样的方法为何在高层失效（压缩版；完整分析见附录 C）

上述论点本身也预言了它的边界。临近输出处，一层的 residual 已经接近 logit，因此它的
**主计算方向与输出 token 方向趋于重合**（附录 C.2）。于是高层 steering 向量会越来越多地把容量
**花在直接改写 next-token 分布上**，而非内部模式——向量中的反思词（Wait/But/…）成分随层深单调上升、
在最顶层达到峰值（附录 C.1）。但"用一个全局向量直接改写输出"是一个**病态目标**：
不同位置需要不同的下一个 token，单个加性方向面临不可调和的逐位置梯度冲突（附录 C.3），
其表现正是图 1 的两种病态——norm 爆炸或梯度消失。全参 / LoRA 之所以不受此限，
是因为它们编辑的是**权重（计算）**，而非单个全局方向。

> 需强调这是**程度问题、而非本质区别**：norm-controlled 的因果消融显示，把 token 方向分量去掉
> （保持 norm 不变）后，高层向量对输出的影响**仍大部分保留**（附录 C.4）。因此我们说高层向量是
> **越来越偏向输出 token 空间**，而非"纯粹地操纵 token"。

## X.4 诠释：RL 所学能力被约束在什么空间里

把反常现象（X.1）、正面论点（X.2）与边界（X.3）合起来，可以沿三个轴刻画 RL 增益的
**栖息位置（locus）与作用范围（range）**，每个轴都有测量支撑：

- **深度轴。** RL 增益的**可加性表征存在于中低层**。高层仍携带 RL 信号（全参/LoRA 成功），
  但在高层，该增益**不以加性形式存在**——它与"操纵输出 token"无法分离。

- **层内几何轴。** 方向落在 hidden 的**低方差 / 与输出正交**子空间里
  （logit-lens 熵 = 随机基线；与 hidden 均值方向 cos ≈ 0，附录 C.2）。
  RL 改变的是一个模型**并不用来直接写 token**、必须靠后续层"算过去"的方向。

- **维度轴（每层一个近乎 1 维的典范方向）。** 在**独立训练**（不同层范围、学习率、随机种子）下，
  为**同一层**学到的向量收敛到**几乎相同的方向**：平均两两余弦 **0.5–0.83**
  （而 ℝ²⁵⁶⁰ 中随机向量 ≈ 0），中层最高（约 0.82）。把这些独立解堆叠做 SVD，
  得到**每层参与比（participation ratio）≈ 1.3–2.0**——即每层的 RL 增益占据一个
  **1–2 维的典范子空间**，而非随机可行解（附录 C.6，图 C-consistency）。

**合起来——一句话的答案。**
> RLVR 相对基座新增的能力，被约束在一个**低维（每层约 1–2 维）、与输出正交的"推理模式"子空间**里，
> 且这个子空间**位于中低层**。它低秩（所以能被少量 steering 向量复现——Finding 1）、
> 方向**典范**（独立训练互相吻合）、位置**确定**（中低层、尾空间）。
> 高层的 RL 信号确实存在，但无法被压缩成一个加性方向——只能通过编辑权重（全参/LoRA）触及，
> 而非通过 steering。

这为"RL 改变了什么、改在哪里"给出了一个受机制约束的回答：**RL 改变的不是模型的直接输出映射，
而是中低层一组紧凑、典范的推理计算方向。**
